## Project Status

🚧 **Early Prototype / Pre-MVP**

BuildBot Lab currently has an experimental browser-based prototype
implemented as a standalone HTML file.

The prototype demonstrates:

- 2D differential-drive robot simulation
- motor control
- simulated distance sensing
- simulated ground sensors
- basic collision detection
- predefined challenges
- a sandbox interface
- simple block-based command sequencing
- an experimental Python-like programming interface

The current prototype is intended to validate the educational concept.

It is not yet considered the production architecture of BuildBot Lab.
Features, APIs, physics behavior, sensor models, and simulation accuracy
must still be independently verified.
